# Contributing

Obrigado por querer contribuir!

## Regras rápidas
- Não inclua logs/relatórios com caminhos pessoais.
- Não faça PR que mude o comportamento “read-only” sem discutir antes.
- Foque em UX, documentação e estabilidade.

## Como contribuir
1) Fork do repositório  
2) Crie uma branch (`feature/minha-melhoria`)  
3) Faça PR descrevendo: o problema, a solução e como testar
