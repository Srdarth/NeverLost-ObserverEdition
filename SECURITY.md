# Security Policy

## Supported Versions
Este projeto está em fase inicial. Recomenda-se usar sempre a versão mais recente do release/pacote.

## Reporting a Vulnerability
Se você encontrar qualquer comportamento suspeito (ex.: algo que pareça “enviar dados”), abra uma Issue com o máximo de detalhes **sem anexar arquivos pessoais**.
Se preferir, reporte de forma privada via X: **@3ddY99**.
